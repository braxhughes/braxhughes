## Shipped and public

### [agent-bell](https://github.com/braxhughes/agent-bell)

Two quiet sounds for Claude Code: one when the agent needs you, one when it's done. One
command to mute. Ships as a Claude Code plugin, so the hooks install themselves and
nothing touches your `settings.json`.

```
/plugin marketplace add braxhughes/agent-bell
/plugin install agent-bell@braxhughes
```

MIT · v0.3.0

### [claude-statusline](https://github.com/braxhughes/claude-statusline)

A Claude Code status line that tells you when to switch accounts — before you hit the
usage wall mid-task, not after. Account, model, project, branch, context, and how much
of your 5-hour pool is gone, on one line.

```sh
git clone https://github.com/braxhughes/claude-statusline.git
cd claude-statusline && ./install.sh
```

MIT · v0.2.0

### [mossprint](https://github.com/braxhughes/mossprint)

The public repository for MOSS. Every release ships installers you can download and run
on macOS, Windows, and Linux.

[Download the latest release →](https://github.com/braxhughes/mossprint/releases/latest)
